## 2026-11-19 — фирменный баннер итога матча (утверждён пользователем)
- Итог матча публикуем СРАЗУ после финального свистка (~30 мин), не на следующий день — на следующий день уже поздно.
- Стиль утверждён: `engine/poster_result.html` (v3: ткань в цветах команд, шрифт Big Shoulders, щиты с кодами, блок Model check). Рендер: `python3 engine/shot_result.py engine/data/<slug>.json` → `result_feed.jpg` (1080×1350) и `result_story.jpg` (1080×1920).
- Поля JSON: slug, home, away, code{home,away}, colors{home,away}, league, round, venue, date, final, probs, pick, pickOk, score, story.short (одна строка о матче, только факты из 2 источников).
- Без реальных гербов и логотипов клубов/федераций — только щиты с кодами.
- Публикация: Instagram пост + Story, Threads, Pinterest. Дальше — анимация в этом же стиле для TikTok/Reels.
- Другие форматы: `tpl_paper.html` (газета, lo-fi музыка `sound_paper.wav`) — запасной стиль для разнообразия.
