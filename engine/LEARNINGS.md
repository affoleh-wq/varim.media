## Правила на завтра (утренняя задача применяет их и перечисляет в сообщении на согласование)

1. **График (решение пользователя 18.11):** первый матч — сразу после «да» (≈+10 мин), каждый следующий — через 1 час. Внутри часа: TikTok + IG Reel → +5 мин IG Story (тот же mp4, без текста) → +15 мин Threads → +30 мин Pinterest. Старт не раньше 17:00 по Кишинёву (подтверждено 19–20.11: вечерние посты IG 38–48 за 4 ч).
2. **Первый кадр любого ролика = крючок подписи крупным текстом, без ответа модели** (новое 20.11). `tpl_top3.html`: сцена 1 вместо «3 STATS TO KNOW» — факт-шок («MAN CITY: 1 WIN IN 5») + команды, «3 stats» мелкой плашкой. Почему: City 3 Stats с общим заголовком — пропуск 94.6%, 1.3 с; Quiz с вопросом «Gladbach or Dortmund?» — 79.5%; Verdict v2 с хуком «6–3 last time. Again?» — 66.7%. Проверка: пропуск < 80%.
3. **Убрать пустые серые квадраты флагов** в tpl_top3/tpl_quiz для клубов: щит с кодом команды в её цветах (как poster_result) или ничего. Сейчас выглядит как сломанная картинка в первом кадре.
4. **Матчи — только топ-лиги Европы** (АПЛ, Ла Лига, Бундеслига, Серия А, Лига 1), если есть в ближайшие 24 ч; Бразилия — только если их нет. Подтверждено: 20.11 АПЛ/Бундеслига 38–48 за 4 ч vs 19.11 5–7 в том же возрасте; Бразилия 13–16 за 2 дня.
5. **Score Quiz — минимум 1 ролик в день** (лидер теста: IG 83 сред., пропуск 76%). Verdict 12 v2 — не больше 1 в день до подтверждения (6 просм., мало данных).
6. **Threads — только картинки, первая строка — вопрос со знаком «?»**. 20.11 правило нарушено в 2 из 3 постов → 0 просмотров за 2.5–4.5 ч (19.11 с вопросами 9–13). TikTok — правила модерации ниже.

Снято 20.11: «проверить Pinterest» — пины 16–17.11 получили первые показы (5–11) на 3–4-й день; просто ждать.

## 2026-11-19 — фирменный баннер итога матча (утверждён пользователем)
- Итог матча публикуем СРАЗУ после финального свистка (~30 мин), не на следующий день — на следующий день уже поздно.
- Стиль утверждён: `engine/poster_result.html` (v3: ткань в цветах команд, шрифт Big Shoulders, щиты с кодами, блок Model check). Рендер: `python3 engine/shot_result.py engine/data/<slug>.json` → `result_feed.jpg` (1080×1350) и `result_story.jpg` (1080×1920).
- Поля JSON: slug, home, away, code{home,away}, colors{home,away}, league, round, venue, date, final, probs, pick, pickOk, score, story.short (одна строка о матче, только факты из 2 источников).
- Без реальных гербов и логотипов клубов/федераций — только щиты с кодами.
- Публикация: Instagram пост + Story, Threads, Pinterest. Дальше — анимация в этом же стиле для TikTok/Reels.
- Другие форматы: `tpl_paper.html` (газета, lo-fi музыка `sound_paper.wav`) — запасной стиль для разнообразия.
